# @alexsab-ru/scripts

Сначала [workspace AGENTS](../AGENTS.md). Общий npm-пакет клиентских функций сайтов и CLI обработки фидов; это отдельный Git, не папка скриптов метапроекта.

## Где искать

`lib/` — analytics, form, Calltouch, cookie, campaign и связанные runtime helpers. Точные экспорты и CLI — `package.json`. Поведение API описано в [README_RU.md](README_RU.md), включая `/api/leads`, request_id, CallbackLead и исключение персональных полей из аналитики.

## Работа и проверки

- `pnpm test` из этой папки запускает `node --test` (точный script — package.json).
- При изменении поведения добавить регрессионный тест; читать существующие тесты и форматирование соседнего кода.
- Сохранять совместимость форм и lead-attempt: повтор неизменённой попытки не должен создавать повторный callback.
- Клиентский success/приём заявки не доказывает доставку всех серверных каналов.
- Изменение локального пакета не равно обновлению дилерских сайтов. Версию, публикацию npm и обновление зависимостей выполнять в рамках отдельно разрешённого выпуска.

Связанные проекты: `../astro-components` — потребитель, `../lead` и `../lead-service` — серверные контракты. Не выводить реальные данные заявок или секреты в тестах/документации.
